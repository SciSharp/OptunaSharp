## How this run works

1. Pick the next direction from the queue below and mark it **in progress**.
2. Read the Optuna source for the area, then run Python first and record what it does.
3. Run the same inputs through OptunaSharp (a scratch probe console that references the built Core), diff.
4. Every difference becomes a finding (ID `QA-n`), with severity, a reproduction test and an explanation.
5. New ideas go to the queue; a direction that needs an owner decision is **paused** with its question listed
   under "Questions for the owner".

Severity: **HIGH** = wrong results/crash on a common path; **MEDIUM** = wrong results/messages on a less common
path; **LOW** = cosmetic or exotic-input divergence; **NIT** = message wording only.

Known issues already inventoried in the catalog (`optunasharp/optunasharp.md`, Open items 17–24) are not
re-reported here.

## NumSharp findings (dependency, not reachable from OptunaSharp today)

Found while chasing QA-41 / QA-42 (D83). No OptunaSharp call site hits them — every `randint` range in Core is at
most `2**31 - 1`, and Core never calls NumSharp's `choice` (it builds permutations from `shuffle`) — so they have
no OptunaSharp test; they belong in NumSharp (`refs/NumSharp`, `src/NumSharp.Core/RandomSampling/`).

| ID | Area | Summary |
|----|------|---------|
| NS-1 | `NumPyRandom.choice(long a, Shape size, bool replace, double[] p)` | `replace` is never read: `replace=False` samples with replacement. `RandomState(seed).choice(5, 5, replace=False)` repeats a value for 191 of 200 seeds (seed 0: `4,0,3,3,3`); numpy returns `permutation(5)[:5]` (seed 0: `[2 0 1 3 4]`) and raises when `size > a`. |
| NS-2 | `NumPyRandom.randint`, ranges `(2**31 - 1, 2**32]` | NumSharp switches to 64-bit draws (`NextLong`, two words, value from the second) once `high - low` exceeds `int.MaxValue`; numpy stays on the 32-bit generator while `high - low - 1 <= 0xFFFFFFFF` (and returns `low + next_uint32` for a range of exactly `2**32`). `RandomState(1)`, after one `randint(0, 2**31 - 1)`: `randint(0, 2**31)` is `2135392491` in numpy, `946286476` in NumSharp. |
