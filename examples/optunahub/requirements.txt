# Python prerequisites for the OptunaHub examples in this folder.
#
# The bridge (OptunaSharp.Interop.pythonnet) embeds CPython and loads real OptunaHub packages, so it
# needs these in the interpreter it hosts. Install with:
#
#     pip install -r examples/optunahub/requirements.txt
#
# (the run-optunahub.sh / run-optunahub.bat launchers do this for you.)

optuna              # the optimization framework the bridge talks to
optunahub           # the OptunaHub loader (optunahub.load_module / load_local_module)

# OptunaHubDashboard.cs — view the persisted study in the real Python dashboard (the launcher opens it)
optuna-dashboard    # https://github.com/optuna/optuna-dashboard — reads the SQLite study OptunaSharp writes

# OptunaHubBenchmark.cs — BBOB (benchmarks/bbob) wraps the COCO experiment suite
coco-experiment

# OptunaHubSamplerShootout.cs — the hub samplers' own backends (any missing one is skipped, not fatal)
cmaes               # samplers/cmaes  (also needed by samplers/auto_sampler, below)
pandas              # samplers/nelder_mead
scipy               # samplers/auto_sampler  (its AutoSampler imports cmaes + scipy + torch at load)

# OptunaHubCode1.cs / OptunaHubDashboard.cs use samplers/auto_sampler, which hard-imports PyTorch. torch
# is large and platform-specific, so it is NOT auto-installed here. Install the CPU build if you want the
# AutoSampler examples to run the real hub sampler:
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
# Without it, OptunaHubCode1 prints guidance and OptunaHubDashboard falls back to OptunaSharp's native TPE
# (so the study is still persisted and the dashboard still opens).
