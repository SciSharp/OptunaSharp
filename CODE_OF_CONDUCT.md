# Code of Conduct

OptunaSharp is part of the [SciSharp STACK](https://github.com/SciSharp) and adopts the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, welcoming, and constructive. Harassment or exclusionary behavior of any
kind is not tolerated. Report unacceptable behavior by opening a confidential issue or contacting a
project maintainer.

The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
